This portfolio website serves as a comprehensive showcase of my web development skills acquired throughout the semester. The site demonstrates proficiency in HTML5, CSS3, JavaScript, responsive design, and deployment practices while presenting my professional experience and technical projects in an accessible, user-friendly format.

3. JavaScript Web Applications

The following interactive applications were developed and deployed as part of this project:

1. Auto Image Slider

Interactive carousel with auto-play, manual controls, dot indicators, and thumbnail navigation

2. MPG Calculator

Miles per gallon calculator with real-time validation and fuel efficiency calculations

3. Invoice Calculator

Professional invoice generator with dynamic rows, tax calculations, and automatic totals

4. Mortgage Calculator

Home loan payment calculator using compound interest formulas and number formatting

3.1 JavaScript Concepts Demonstrated

  • Variables & Data Types: let, const, var declarations
  • Functions: Function declarations, arrow functions, callback functions
  • Control Flow: if/else statements, for loops, while loops
  • DOM Manipulation: getElementById, querySelector, classList methods
  • Event Handling: onclick, oninput, addEventListener
  • Mathematical Operations: Formulas for MPG, mortgage payments, tax calculations
  • String Manipulation: Number formatting, substring operations
  • Form Validation: Input validation, error handling, user feedback

4. Design Specifications

4.1 Visual Design

  • Typography: DM Serif Display (headings), DM Sans (body text)
  • Color Palette:
    • Primary: #1A56DB (Blue)
    • Background: #F5F0E8 (Cream)
    • Text: #111111 (Ink Black)
    • Muted: #6B6B6B (Gray)
  • Layout: Clean, professional design with ample white space

4.2 Responsive Design

  • Mobile-first approach with breakpoint at 768px
  • Hamburger menu for mobile navigation
  • Flexible grid layouts that adapt to screen size
  • Touch-friendly button sizes and spacing
